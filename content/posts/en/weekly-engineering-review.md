## Why ask the same questions?

Free-form writing is useful for discovering ideas, but it is not always good for comparing one period with another. A fixed set of questions gives me a stable reference for seeing which work is moving forward and which problems keep returning in a new disguise.

At the end of a week, I ask:

1. What did I actually complete, and how can it be verified?
2. Which judgment changed in response to new evidence?
3. Which point of friction appeared more than once?
4. If I could keep only one priority next week, what would it be?

## Outcomes need to be specific

“Looked into search” is not an outcome; “finished search filters whose state survives in the URL” is. A verifiable statement exposes remaining work and prevents time spent from being mistaken for progress.

A review need not become a long essay. Two or three sentences per question are often enough. What matters is using the same structure consistently and being willing to revisit last week's decisions.

## Make the next step small enough

The final question permits only one priority. It is not the only task to do, but it provides an ordering rule when tasks compete. A clear priority protects attention better than a task list that grows without limit.
